# Data Analytics: проекты и практические работы

Учебные проекты по курсу аналитики данных: SQL, A/B-тестирование и статистика, причинный анализ (эконометрика) и продуктовые метрики. Данные во всех работах синтетические.

**Стек:** Python (Pandas, NumPy, Matplotlib), SQL (SQLite), Jupyter Notebook

## Структура репозитория

```
Data_Analytics/
├── 01-sql/
├── 02-ab_testing-statistics/
├── 03-econometrics/
└── 04-business-interpretation/
```

## 01. SQL — [`01-sql`](01-sql/)

Решение аналитических SQL-задач с автоматической проверкой результата.

| Файл | Что сделано |
|---|---|
| `sql_lecture_1_homework_autograded.ipynb` | Подзапросы, группировки, CTE и оконные функции на примере интернет-магазина: LTV-сегменты, топ-3 товара по категориям, промокоды, repeat-rate по городам, активация пользователей в первые 7 дней, поиск аномально крупных заказов. |
| `sql_lecture_2_homework_autograded.ipynb` | Оптимизация SQL-запросов: подбор индексов (в том числе композитных), анализ плана выполнения, переписывание запросов (предварительная агрегация, `NOT EXISTS` вместо `DISTINCT`), выбор индексов с учётом компромиссов. |

## 02. A/B-тесты и статистика — [`02-ab_testing-statistics`](02-ab_testing-statistics/)

Методы анализа экспериментов и повышения их чувствительности.

| Файл | Что сделано |
|---|---|
| `cuped_homework_autograded.ipynb` | CUPED: расчёт коэффициента коррекции вручную, построение скорректированной метрики, сравнение стандартной ошибки с обычной оценкой, разбор неправильной ковариаты, итоговый отчёт с доверительными интервалами. |
| `stratification_homework_autograded.ipynb` | Стратификация: сравнение наивной и стратифицированной оценки эффекта, расчёт по стратам и весов, сравнение ширины доверительных интервалов. |
| `bandits_homework_autograded.ipynb` | Многорукие бандиты: реализация epsilon-greedy и Thompson Sampling, расчёт cumulative regret, сравнение алгоритмов по суммарной награде и доле выбора лучшей ручки. |

## 03. Эконометрика — [`03-econometrics`](03-econometrics/)

Теоретические и расчётные работы (PDF).

| Файл | Что сделано |
|---|---|
| Propensity Score Matching (кейс) | Оценка причинного эффекта акции с кешбэком без рандомизации: ATT, смещение отбора, почему наивное сравнение групп не даёт причинный эффект. |
| Линейная регрессия (домашняя работа) | Метод наименьших квадратов: расчёт коэффициентов простой регрессии вручную и их интерпретация. |

## 04. Продуктовые метрики и бизнес-интерпретация — [`04-business-interpretation`](04-business-interpretation/)

| Файл | Что сделано |
|---|---|
| `Metrics_Homework.ipynb` | Базовые продуктовые метрики: проверка качества данных и дублей, DAU и уникальные активные пользователи, конверсия в покупку, когортный retention (Day-1, Day-7), Revenue, ARPU, ARPPU, AOV, сравнение каналов (organic и paid) с выводами об ограничениях данных. |
| `FocusFlow_Homework_Student.ipynb` | Комплексный кейс продуктового аналитика (мобильное приложение для задач, бесплатный тариф и подписка): проверка данных, Customer Journey Map и план трекинга, leading и lagging метрики, AARRR, HEART, North Star Metric, Metric Tree, когортный анализ, диагностика проблем на Android, unit-экономика каналов, приоритизация гипотез и дизайн эксперимента, итоговая записка для Product Manager. |

## Что показывают проекты

- уверенная работа с SQL: оконные функции, CTE, оптимизация запросов;
- методы анализа A/B-тестов: CUPED, стратификация, бандиты;
- понимание причинных оценок: PSM, различие между наблюдательным и причинным эффектом;
- продуктовые метрики и когортный анализ, умение формулировать выводы и рекомендации для бизнеса.
